Why WebPViewer

WebP is a modern image format used across the web, but macOS doesn't always open it natively — especially on older versions like macOS Catalina. WebPViewer is a small, focused app that opens WebP images instantly: double-click a .webp file in Finder, drag one onto the window, or pick a folder in the sidebar. No browser, no online converter, no slowdowns.

Features

Native & fast

Pure AppKit, written in Swift. Universal binary for Apple Silicon and Intel. Opens an image in under a second.

Many formats

WebP, PNG, JPEG, GIF, BMP, TIFF, and HEIC. All in one viewer.

Folder sidebar

Browse Pictures and Downloads out of the box, add any folder via "+ Add Folder…". Access is preserved between launches.

Thumbnail strip

See neighboring images at a glance. Click to jump, or use ←/→ arrow keys to walk the folder.

Zoom & rotate

Fit to window, 1:1, zoom in/out with keyboard or trackpad, rotate left/right, fullscreen.

Catalina compatible

Works on macOS 10.15 (Catalina) and newer. Universal binary, signed for the Mac App Store.

No data collection

WebPViewer doesn't send anything anywhere. It runs entirely on your Mac.

Keyboard navigation

Arrow keys, Home/End, Space for fit, ⌘+/⌘− for zoom, ⌃⌘F for fullscreen.

Requirements

macOS 10.15 (Catalina) or newer. Works on both Apple Silicon and Intel Macs.
